# Oraya — Claude Design Seed (Phase 16C Welcome Book)

This folder is the **only** content intended for upload to a Claude Design project.
It is a **brand + content seed**, not a design system export.

## What this seed is for

Claude Design should use this seed to **explore new professional design directions**
for the Oraya printable villa welcome book — new page composition, rhythm, hierarchy,
and editorial systems — while keeping the Oraya brand identity.

## What this seed is NOT

- It is **not** a component library to reproduce.
- It is **not** a spec of the current V2 prototype.
- **The current V2 prototype is a checkpoint, not the target.** Do not copy its layout.
  Its weaknesses are documented in `CURRENT_V2_CRITIQUE.md` precisely so new
  explorations can move past them.

## Files

| File | Purpose |
|---|---|
| `ORAYA_BRAND_CONTEXT.md` | Brand identity: palette, typography, voice, motifs — the constants |
| `WELCOME_BOOK_CONTENT_BRIEF.md` | Approved content and structure — the facts (content reference only) |
| `DESIGN_EXPLORATION_BRIEF.md` | The design task, print constraints, photo-slot rules, quality bar |
| `CURRENT_V2_CRITIQUE.md` | Honest critique of the current V2 — what to move beyond |

## Hard rules for any exploration

1. Keep the Oraya brand identity (palette, type pairing, tone). Everything else —
   layout, grid, page count within print limits, section order, visual devices — is open.
2. Use `WELCOME_BOOK_CONTENT_BRIEF.md` as **content reference only**, never as a layout map.
3. **Do not invent** facts, amenities, services, photos, safety instructions, or emergency information.
4. **No fake final photography.** Missing photos must be handled elegantly
   (see photo-slot rules in the exploration brief).
5. Target: minimum **9/10 professional visual direction**, designed in Figma / Claude Design
   **before** any HTML/CSS implementation.

## Deliberately excluded from this seed

Current V2 HTML/CSS (to avoid anchoring), exported PDFs, screenshots, QR codes,
map URLs, helper scripts, and all application/backend code. Sensitive values
(door PINs, Wi-Fi password) are represented as placeholders only.
