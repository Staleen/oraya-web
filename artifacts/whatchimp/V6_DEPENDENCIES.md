### Normalization response mapping (7466 and 8101)

The backend returns an additive `extracted_text` object whose values are **always strings**, with the literal string `"null"` for any field the current message did not contain. **Bind the mappings to `extracted_text.*` — NEVER to `extracted.*`.** The live test of 2026-07-04 had the mapping on `extracted.*`, whose JSON `null` values WhatChimp wrote as empty strings — the blank check-out that produced a dated summary with a blank date line.
